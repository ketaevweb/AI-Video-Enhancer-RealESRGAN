# AI Video Enhancer (Real-ESRGAN realtime)

Смотрите свою коллекцию фильмов 480p/720p на мониторе 2K так, как будто её «дорисовал» телевизор с AI-процессором: настоящий **Real-ESRGAN** прогоняет **каждый кадр** через нейросеть на вашем GPU в реальном времени — апскейл, восстановление детальности, шумоподавление. Никаких приближённых шейдеров: это полноценная нейросеть Real-ESRGAN, выполняемая TensorRT-движком, собранным под вашу видеокарту.

```
mpv ──► VapourSynth (.vpy) ──► vs-mlrt/vstrt (TensorRT fp16)
        │                            │  «честный» Real-ESRGAN на GPU
        │                            ▼
        └────────────────  кадр 4K возвращается в mpv ──► монитор 2K
```

Всё работает в моменте — без обработки файлов, без перекодирования, без ожидания. Открыли фильм — картинка уже улучшается.

---

## Что даёт этот пайплайн

* **Честный Real-ESRGAN** — полноценные веса (RRDBNet и компактные v3-модели), а не аниме-шейдеры Anime4K и не упрощённые аналоги. Именно это семейство моделей даёт «телевизорный» апскейл.
* **TensorRT fp16-движки**, собранные один раз под конкретно вашу GPU — на порядок быстрее универсального ONNX-рантайма и заметно быстрее, чем то же самое в ONNX Runtime.
* **Умная геометрия**: исходный кадр вписывается во вход нейросети с сохранением пропорций (вписывание + добивка полями + обрезка после апскейла). Никаких растянутых лиц на широкоэкранных фильмах.
* **Умные цвета**: цветовая матрица и диапазон берутся из свойств кадра (BT.709 / BT.601, limited/full), выход отдаётся mpv в 10 бит, чтобы mpv сам дизерил на выходе — без бандинга на тёмных сценах.
* **Автовключение**: SD- и 720p-источники усиливаются автоматически, 1080p и выше идут без обработки (там нейросеть только тратила бы GPU).

## Требования

| Компонент | Минимум |
|---|---|
| GPU | NVIDIA с 8+ ГБ VRAM, свежий драйвер (тестировалось на RTX 3080) |
| ОС | Windows 10/11 x64 |
| CPU/RAM | любой современный 4+ ядра / 16+ ГБ |
| Диск | ~4 ГБ (пакет vs-mlrt ~1.6 ГБ + модели + движки) |
| ПО | Python 3.12+, VapourSynth **R79**, mpv (сборка shinchiro и т.п.) — ставятся/закрепляются автоматически |

> **Почему VapourSynth строго R79:** плагин `vstrt` в vs-mlrt (все выпущенные версии на октябрь 2026, включая линейку v15.x и v16.x-test) собран под API3, а VapourSynth R80 удалил поддержку API3-плагинов (issue #171 в репозитории vs-mlrt). На R80/R81 плагин не загружается с ошибкой «uses API 3, which is no longer supported». Установщик сам определяет R80+ и откатывает VapourSynth на R79 (для pip-установки — `pip install vapoursynth==79`, движки и модели при этом не затрагиваются). Когда vs-mlrt выпустит официальный API4-релиз, можно будет вернуться на свежие версии.

## Установка

1. Скачайте репозиторий (Code → Download ZIP) и распакуйте в любую папку, например `E:\Movies\AI-Video-Enhancer-RealESRGAN`.
2. Откройте PowerShell **от администратора** в этой папке и запустите:
   ```powershell
   powershell -ExecutionPolicy Bypass -File .\install.ps1
   ```
3. Установщик сам поставит Python/VapourSynth (если их нет), скачает vs-mlrt и модели, и запустит сборку TensorRT-движков. Движок собирается один раз под вашу видеокарту:
   * компактные модели (`realesr-*`) — минуты;
   * RRDB-модели (`RealESRGAN_*`) — 5–15 минут каждая, окно может «зависнуть» — это нормально, прогресс пишется в `C:\AIVideoEnhancer\logs\`.
4. Проверьте скорость:
   ```powershell
   powershell -ExecutionPolicy Bypass -File C:\AIVideoEnhancer\scripts\test-speed.ps1
   ```
   Все движки, отмеченные `OK`, тянут 24 fps в реальном времени.

Всё последующее время движки не пересобираются: переустановка/обновление скриптов безопасны и занимают секунды.

## Как смотреть

**Способ 1 — ярлыки (ничего настраивать не надо):**

* `C:\AIVideoEnhancer\watch-AI-general.bat` — **основной профиль для фильмов (QUALITY v9)**: ИИ (realesr-general-x4v3, НЕ аниме-модель) с возвратом исходной текстуры работает на ЛЮБОМ источнике — и на DVD (480p/576p), и на 720p-рипах. Модель убирает шум сжатия, бандинг и «лесенки» из стриминговых рипов, а возврат ~35% исходной текстуры сохраняет естественность (без эффекта «мультфильма»). Ориентир скорости на RTX 3080: ~12–18 fps
* `C:\AIVideoEnhancer\watch-AI-anime.bat` — аниме и мультфильмы (realesr-animevideov3, 960x540 → 4K, ~23 fps на RTX 3080). Рисованная картинка здесь — это ПРАВИЛЬНО, для игрового кино этот профиль не предназначен
* `C:\AIVideoEnhancer\watch-AI-film.bat` — опциональный режим детализации (x4v3 @ 640x360 → 2K, ~10–15 fps): микродетали ценой естественности — модель стирает зерно и «придумывает» текстуры
* `C:\AIVideoEnhancer\watch-AI-general-denoise.bat` — прежний ярлык, полностью равен `general` (оставлен, чтобы старые ярлыки не сломались)
* `C:\AIVideoEnhancer\watch-AI-film-hd.bat` — RRDB x2plus, офлайн-качество (~5 fps) — только для ночной пакетной перекодировки, не для просмотра
* `C:\AIVideoEnhancer\watch-AI-debug.bat` — диагностика: запускает mpv с видимой консолью, пишет лог и открывает его в Блокноте. Если обычные ярлыки «не запускаются» — перетащите фильм на этот

Перетащите фильм на ярлык (или запустите: `watch-AI-general.bat "D:\Films\movie.mkv"`). Прямо во время просмотра переключать режимы можно хоткеями: **Ctrl+a** — фильмы (умный профиль), **Ctrl+n** — аниме, **Ctrl+f** — film (детализация), **Ctrl+0** — выключить ИИ.

**Почему фильм выглядел мультфильмом (история изменений QUALITY v8 → v9):** с раунда PERF v6 основным профилем была модель `realesr-animevideov3` — она обучена на аниме-видео, поэтому на игровом кино «раскрашивала» кадр: плоские заливки, стёртые кожа/ткань/плёночное зерно, рисованные контуры. В v8 основной профиль для 720p+ вообще отключал ИИ (честный Spline36) — но на рипах со стриминга (1 Мбит/с) это оставляло шум сжатия и «лесенки», а картинка «не улучшалась». Итог в v9: ИИ снова работает на всех источниках, но на общей модели x4v3 (не аниме) и с возвратом ~35% исходной текстуры (`AIVH_DETAIL`) — шум убирается, естественность остаётся. Хотите совсем без ИИ на конкретном фильме — жмите **Ctrl+0** (чистый mpv с ewa_lanczos + deband) или задайте `AIVH_HDAI=0`. Для анимации ( Disney/Pixar/аниме) лучший результат и максимальная скорость — по-прежнему профиль `anime` (**Ctrl+n**).

**Способ 2 — конфиги mpv (деплоятся автоматически):**

Установщик копирует `mpv.conf` и `input.conf` в `portable_config\` рядом с вашим `mpv.exe` — единственное место рядом с бинарником, которое mpv реально читает (файлы, лежащие рядом с mpv.exe снаружи этой папки, mpv игнорирует). Хоткеи из `input.conf` поэтому работают при любом запуске. Если хотите, чтобы любой SD/720p-файл, открытый прямо в mpv (без ярлыков), усиливался сам — раскомментируйте блок `[aivh-sd]` в `portable_config\mpv.conf`. Держите его закомментированным, если смотрите через `watch-AI-*.bat`: ярлык уже добавляет фильтр сам, а активный профиль добавил бы второй — модель работала бы дважды на кадр.

## Выбор модели

| Профиль | Модель | Вход движка → выход | Для чего |
|---|---|---|---|
| `general` | realesr-general-x4v3 + возврат текстуры | 640x360 → 2560x1440 | **Основной для всего, включая 720p**: модель чистит шум сжатия/бандинг/лесенки стриминговых рипов, возврат ~35% исходной текстуры держит естественность; ~12–18 fps на RTX 3080 |
| `anime` | realesr-animevideov3 | 960x540 → 3840x2160 | Только аниме/мультфильмы (~23 fps); рисованный стиль здесь — цель, а не дефект |
| `film` | realesr-general-x4v3 | 640x360 → 2560x1440 | Опциональный режим детализации (~10–15 fps): максимум микродеталей ценой естественности — зерно стирается, текстуры синтетические |
| `film-hd` | RealESRGAN_x2plus | 1280x720 → 2560x1440 | RRDB, офлайн-качество (~5 fps) — только ночная пакетная перекодировка |

Скорость зависит от GPU: ориентируйтесь на вердикты `test-speed.ps1`. Вычислительная нагрузка растёт от числа пикселей на выходе модели. Тонкая настройка профиля `general` (переменные окружения, задаются до запуска ярлыка): `AIVH_DETAIL` — доля возврата исходной текстуры (0 = чистый ИИ, «детально»; 0.35 по умолчанию; 0.6+ — максимально естественно); `AIVH_HDAI=0` — не запускать ИИ на HD-источниках (поведение v8). Максимальное качество без компромиссов — ночная пакетная обработка `film-hd` (RRDB x2plus 720p→1440p).

## Диагностика

* **Логи сборки движков:** `C:\AIVideoEnhancer\logs\build_<модель>.out.log` / `.err.log`
* **Перетащил фильм на `watch-AI-*.bat` — окно не появляется или мигает и исчезает:** перетащите фильм на `watch-AI-debug.bat`: он запустит mpv с видимой консолью, сохранит полный лог в `C:\AIVideoEnhancer\logs\mpv-debug.log` и откроет его в Блокноте. Пришлите содержимое лога — в нём будет точная причина (не найден скрипт/движок, VapourSynth не загрузился и т.п.).
* **Сборка упала?** Просто запустите `build-engines.ps1` ещё раз — готовые движки пропускаются, недостроенные пересобираются. Форс-пересборка: `build-engines.ps1 -Force`.
* **Лёгкий вариант:** `install.ps1 -Minimal` — не собирает тяжёлый x2plus-движок (профиль `film-hd` тогда сам переключается на 540p-движок).
* **Историческая ошибка `NativeCommandError` на `build-engines.ps1:57`** — лечится этой версией скриптов: TensorRT печатает весь прогресс в STDERR, а Windows PowerShell со `$ErrorActionPreference='Stop'` считал такую строку фатальной ошибкой и убивал сборку через 3 секунды (сообщение про `timing.cache` — безобидное предупреждение первого запуска). Теперь `trtexec` запускается через `Start-Process` с выводом в лог, и успех определяется только кодом возврата.
* **Ошибка `Plugin ... uses API 3, which is no longer supported`** — у вас VapourSynth R80+, а плагин vstrt пока требует API3. Запустите `install.ps1` последней версии: он сам поставит VapourSynth R79 (либо вручную: `py -3.12 -m pip install "vapoursynth==79"`).
* **«Движок не найден» при воспроизведении** — значит не собран соответствующий движок: запустите `build-engines.ps1`.
* **Тормозит**: закройте браузер с аппаратным ускорением (он делит GPU), проверьте `test-speed.ps1`, для старых машин используйте `general`/`anime` — они в разы быстрее RRDB.

## Удаление

```powershell
powershell -ExecutionPolicy Bypass -File .\uninstall.ps1
```
Удаляет `C:\AIVideoEnhancer` целиком. Python, VapourSynth и настройки mpv не трогает.

## Структура

```
install.ps1                  установщик (идемпотентный, можно перезапускать)
build-engines.ps1            сборка TensorRT-движков (устойчива к stderr trtexec)
enhance-film.vpy             чистый режим детализации (x4v3 на любом источнике, опционально)
enhance-film-hd.vpy          пайплайн 720p→1440p (x2plus, с автофолбэком, офлайн)
enhance-anime.vpy            пайплайн аниме (animevideov3)
enhance-general.vpy          умный профиль фильмов: HD — без ИИ (Spline36), SD — x4v3 + возврат текстуры
mpv/mpv.conf, input.conf     конфиги mpv (установщик деплоит их в portable_config\ рядом с mpv.exe)
scripts/test-speed.ps1       замер fps каждого движка
uninstall.ps1
models/                      компактные ONNX-модели (официальные веса, см. ниже)
```

RRDB-модели (x4plus/x2plus) в репозиторий не входят — установщик скачивает их (конвертации в fp16 ONNX с HuggingFace) при установке.
